# IRON BLOOD — четыре модели Claude делают один файтинг

Эксперимент из первого выпуска YouTube-канала «Нейрослоп»: четыре модели Claude получили одно и то же техзадание
([`prompt.md`](prompt.md)) — сделать оригинальный браузерный 2D-файтинг в духе аркад 90-х — и каждая собрала свою игру
в Claude Code. Человек код не писал.

| Папка | Модель | Оценка токенов из отчёта модели | Время работы |
|---|---|---|---|
| [`fable/`](fable) | Claude Fable 5.1 | ≈ 220 тыс. | ≈ 65 мин |
| [`opus/`](opus) | Claude Opus 5.5 | ≈ 500 тыс. | ≈ 164 мин |
| [`sonet/`](sonet) | Claude Sonnet 5.5 | ≈ 570 тыс. | ≈ 52 мин |
| [`haiku/`](haiku) | Claude Haiku 4.5 | ≈ 36 тыс. | ≈ 90 мин |

Цифры — из `data/runs/*.json` каждой версии; это самооценки моделей, а не данные биллинга.

## Запуск любой версии

Нужен Node.js 18+.

```bash
cd opus            # или fable / sonet / haiku
npm install
npm run dev        # http://localhost:5173
```

У каждой версии свой README с управлением и устройством игры. Всё (бойцы, арены, звук) генерируется кодом во время игры,
внешних ассетов нет.
